# 俄罗斯方块（Tetris）

纯 HTML/CSS/JS 实现的俄罗斯方块网页游戏，无任何外部依赖，双击即可游玩。

## 快速开始

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / 现代浏览器）。

如需本地服务器方式：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 玩法与操作

- 目标：控制下落的方块，填满一行即消除并得分；方块堆到顶部即游戏结束。
- 每消 10 行升 1 级，等级越高下落越快（1 级 1000ms/格，逐级加速，最低 80ms）。
- 计分：消 1 行 100 分、2 行 300、3 行 500、4 行 800，再乘以当前等级；软降每格 +1，硬降每格 +2。

| 操作 | 键盘 | 触屏按钮 |
|---|---|---|
| 左移 / 右移 | `←` / `→` | ◀ / ▶（长按连移） |
| 旋转（顺 / 逆） | `↑` / `X` / `Z` | ↻ |
| 软降 | `↓` | ▼（长按连降） |
| 硬降 | `空格` | ⤓ 速降 |
| 暂停 / 继续 | `P` / `Esc` | ⏸ |
| 重新开始 | `R` | 面板按钮 |
| 声音开关 | `M` | 右上角 🔊 |

## 功能特性

- 7 种标准方块（7 袋随机算法，杜绝连续缺块）
- 轻量 SRS 踢墙旋转（靠墙 / 贴底可转正）
- 幽灵方块（落点预测）、下 3 个预览
- 消行闪烁动画 + 得分浮字
- 等级 / 分数 / 消行统计，最高分本地保存（localStorage，禁用存储时自动降级）
- Web Audio 合成音效（无外部资源），可一键静音
- 响应式布局 + 触屏按钮（长按连发），手机 / 平板可用
- 🤖 AI 智能托管：内置确定性算法自动操控（会消行、免配置、毫秒级决策）
- 高分屏（DPR）适配

## 操作小贴士

- 按住 `↓` 或触屏 ▼ 可连续软降；按住 ◀ ▶ 可连续平移。
- 硬降（空格）不打断连击，快速堆叠时善用幽灵方块规划落点。

## 🤖 AI 智能托管

点击侧栏「AI 托管」→「开启 AI 托管」，由内置算法自动操控方块；可随时点按钮停用交还手动。

- **原理**：确定性启发式 AI——枚举当前方块的全部落点（4 个旋转朝向 × 10 列），用评分函数评估每个落点（**消行数 / 堆叠高度 / 最高列 / 洞 / 凸度 / 行过渡**，消行模拟 + 1 步前瞻下一方块），选择最优
- **性能**：毫秒级决策、免配置、零成本、无需联网；实测平均 **79~85 行消行 / 240+ 个方块存活**（熟练玩家水平）
- **基准工具**：`node scripts/bench-algo.js`（统计消行/存活）、`node scripts/search-weights.js`（权重自动搜索）
- 状态栏实时显示 AI 决策（如 `AI：内置算法 落点 第5列 × 旋转1`）；AI 托管时玩家移动/旋转被屏蔽，暂停、重开、声音仍可用
