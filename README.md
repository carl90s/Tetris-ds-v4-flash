# 俄罗斯方块（Tetris）

纯 HTML/CSS/JS 实现的俄罗斯方块网页游戏，无任何外部依赖，双击即可游玩。

## 快速开始

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / 现代浏览器）。

如需本地服务器方式：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 玩法与操作

- 目标：控制下落的方块，填满一行即消除并得分；方块堆到顶部即游戏结束。
- 每消 10 行升 1 级，等级越高下落越快（1 级 1000ms/格，逐级加速，最低 80ms）。
- 计分：消 1 行 100 分、2 行 300、3 行 500、4 行 800，再乘以当前等级；软降每格 +1，硬降每格 +2。

| 操作 | 键盘 | 触屏按钮 |
|---|---|---|
| 左移 / 右移 | `←` / `→` | ◀ / ▶（长按连移） |
| 旋转（顺 / 逆） | `↑` / `X` / `Z` | ↻ |
| 软降 | `↓` | ▼（长按连降） |
| 硬降 | `空格` | ⤓ 速降 |
| 暂停 / 继续 | `P` / `Esc` | ⏸ |
| 重新开始 | `R` | 面板按钮 |
| 声音开关 | `M` | 右上角 🔊 |

## 功能特性

- 7 种标准方块（7 袋随机算法，杜绝连续缺块）
- 轻量 SRS 踢墙旋转（靠墙 / 贴底可转正）
- 幽灵方块（落点预测）、下 3 个预览
- 消行闪烁动画 + 得分浮字
- 等级 / 分数 / 消行统计，最高分本地保存（localStorage，禁用存储时自动降级）
- Web Audio 合成音效（无外部资源），可一键静音
- 响应式布局 + 触屏按钮（长按连发），手机 / 平板可用
- 🤖 AI 智能托管：内置确定性算法自动操控（会消行、免配置、毫秒级决策）
- 高分屏（DPR）适配

## 操作小贴士

- 按住 `↓` 或触屏 ▼ 可连续软降；按住 ◀ ▶ 可连续平移。
- 硬降（空格）不打断连击，快速堆叠时善用幽灵方块规划落点。

## 🤖 AI 智能托管

点击侧栏「AI 托管」→ 选择引擎 → 「开启 AI 托管」，由 AI 自动操控方块；可随时点按钮停用交还手动。

- **双引擎可选**：
  - **强化学习**（默认，越玩越强）：TD(0) 时序差分 + **3 步未来价值** + **经验回放** + **AdaGrad 自适应学习率**，初始权重 = 启发式默认；**10 维特征**（消行/总高/最高列/洞/凸度/行过渡/井深/落点高度 + 两个非线性平方特征）；学习成果存 localStorage 跨局累积，实测 **97 行消行 / 250 方块全存活**
  - **启发式**（稳定备用）：确定性评分——枚举全部落点（4 旋转 × 10 列，含边缘列），按**消行数 / 堆叠高度 / 最高列 / 洞 / 凸度 / 行过渡**评分（消行模拟 + 1 步前瞻），实测平均 **118 行消行 / 300+ 个方块全存活**
- **🎯 总分创新高激励**：RL 每局总分超过历史最高分时，获得**大额回溯激励**；单局每跨过 10 万关口奖励 2000、每跨过 100 万关口奖励 3000（基础 5000，超出纪录每 1 分 +3）——AI 学会"打出高分局"
- **📝 人玩时投喂 RL**（默认开启）：人玩时 RL 观察你的落点做**模仿学习**（Behavior Cloning），带质量门槛（制造高墙/多洞/超高落点不学，防止坏习惯传入）
- **🧹 一键重置 RL 学习**：AI 面板按钮，清除已学权重恢复默认
- **自动训练 N 局**（默认 10，0=关闭）：RL 托管时游戏结束自动重开续训
- **性能**：毫秒级决策、免配置、零成本、无需联网
- **基准工具**：`node scripts/bench-algo.js`（启发式）、`node scripts/bench-rl.js`（RL 学习曲线）、`node scripts/simulate.js`（深度模拟统计）、`node scripts/search-weights.js`（权重搜索）
- 状态栏实时显示 AI 决策与 RL 学习局数（如 `AI：内置算法 落点 第5列 × 旋转1`）；AI 托管时玩家移动/旋转被屏蔽，暂停、重开、声音仍可用
