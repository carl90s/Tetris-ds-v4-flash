# 俄罗斯方块（Tetris）

纯 HTML/CSS/JS 实现的俄罗斯方块网页游戏，无任何外部依赖，双击即可游玩。

## 快速开始

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / 现代浏览器）。

如需本地服务器方式：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 玩法与操作

- 目标：控制下落的方块，填满一行即消除并得分；方块堆到顶部即游戏结束。
- 每消 10 行升 1 级，等级越高下落越快（1 级 1000ms/格，逐级加速，最低 80ms）。
- 计分：消 1 行 100 分、2 行 300、3 行 500、4 行 800，再乘以当前等级；软降每格 +1，硬降每格 +2。

| 操作 | 键盘 | 触屏按钮 |
|---|---|---|
| 左移 / 右移 | `←` / `→` | ◀ / ▶（长按连移） |
| 旋转（顺 / 逆） | `↑` / `X` / `Z` | ↻ |
| 软降 | `↓` | ▼（长按连降） |
| 硬降 | `空格` | ⤓ 速降 |
| 暂停 / 继续 | `P` / `Esc` | ⏸ |
| 重新开始 | `R` | 面板按钮 |
| 声音开关 | `M` | 右上角 🔊 |

## 功能特性

- 7 种标准方块（7 袋随机算法，杜绝连续缺块）
- 轻量 SRS 踢墙旋转（靠墙 / 贴底可转正）
- 幽灵方块（落点预测）、下 3 个预览
- 消行闪烁动画 + 得分浮字
- 等级 / 分数 / 消行统计，最高分本地保存（localStorage，禁用存储时自动降级）
- Web Audio 合成音效（无外部资源），可一键静音
- 响应式布局 + 触屏按钮（长按连发），手机 / 平板可用
- 🤖 AI 智能托管：接入 OpenAI 兼容大模型（DeepSeek / OpenAI / 通义 / Ollama 本地）自动操控
- 高分屏（DPR）适配

## 操作小贴士

- 按住 `↓` 或触屏 ▼ 可连续软降；按住 ◀ ▶ 可连续平移。
- 硬降（空格）不打断连击，快速堆叠时善用幽灵方块规划落点。

## 🤖 AI 智能托管

点击侧栏「AI 托管」→「AI 设置」配置大模型，开启后由 AI 自动读取棋盘并决策放置，可随时点按钮停用交还手动。

- **支持服务商**：DeepSeek（官方推荐 `deepseek-v4-flash`，API 地址 `https://api.deepseek.com`，自动关闭思考模式保证快速响应）/ OpenAI / 通义千问 / Ollama 本地 / 自定义（任意 OpenAI 兼容接口）
- **配置内容**：API 地址、API Key、模型名、动作间隔；「测试连接」可先验证配置是否可用
- **工作方式**：一次请求让模型连续规划 3 个方块（减少 API 往返，显著提速）；若你的模型输出异常，可在 AI 设置里**取消勾选"批量决策"**降级为单方块决策（更简单、模型更易遵循）；每回合将棋盘与方块序列化为文本发给模型，模型返回 JSON（`{"turns":[{"moves":["left","hard"]},...]}`），由游戏逐条执行；模型输出非法时自动容错
- **性能反馈**：状态栏实时显示"AI 思考中… Ns"（决策耗时）与模型输出的动作序列；请求超时 12 秒自动兜底，不会无限卡住
- **容错机制**：请求失败自动落底当前方块；连续失败 2 次自动停用并提示；重开 / 暂停期间旧回合决策不会作用到新局
- **本地免费方案**：安装 [Ollama](https://ollama.com) 后拉取模型（如 `ollama pull qwen2.5:7b`），服务商选「Ollama 本地」即可免 API Key 使用
- **安全提示**：API Key 仅保存在本机浏览器 localStorage，请勿在公共 / 共享电脑上保存；必要时可随时在服务商后台撤销
